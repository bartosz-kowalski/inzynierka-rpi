# inzynierka-rpi

Na RPi:
```bash
python -m venv venv
source venv/bin/activate
pip install ultralytics
pip install numpy
pip install matplotlib
pip install lap
pip install pygame
```

Na windowsie:
```bash
python -m venv venv
source venv/Scripts/activate
pip install ultralytics
pip install numpy
pip install matplotlib
pip install lap
pip install pygame
```
