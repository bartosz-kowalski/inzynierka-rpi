# inzynierka-rpi

Na RPi:
```bash
python -m venv venv
source venv/bin/activate
pip install cv2
pip install ultralytics
pip install numpy
pip install matplotlib
```

Na windowsie:
```bash
python -m venv venv
source venv/Scripts/activate
pip install cv2
pip install ultralytics
pip install numpy
pip install matplotlib
```
